## Vagrant init

```bash
vagrant init bitroid/rockylinux9
```

```bash
vagrant init bitroid/rockylinux9 --box-version 6.0.0
```

## To spin up the instance

```bash
vagrant up
```

## To ssh the instance

```bash
vagrant ssh
```

## To stop the instance

```bash
vagrant halt
```

## To reboot the instance

```bash
vagrant reload
```

## To delete or destroy the instance

```bash
vagrant destroy -f
```
